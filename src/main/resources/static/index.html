Spring AI Multi Agent Runtime

차분한 관제와 실시간 실행 흐름을 하나의 허브에서

이 앱은 입력된 요청을 받아 분석하고, 적절한 에이전트로 라우팅한 뒤, 실행 결과를 스트리밍으로 조합해 반환합니다. 아래 허브에서 각 콘솔/채팅 화면으로 바로 이동해 동작을 검증할 수 있습니다.

앱이 현재 수행하는 일
1. 요청 수신
2. 의도 분석
3. 에이전트 라우팅
4. 도구/서브에이전트 실행
5. 응답 합성 및 스트리밍
운영 상태 가이드
  • 스트리밍 중: 단계 로그와 부분 응답이 실시간으로 쌓입니다.
  • HITL 대기: 승인/취소 결정 전까지 실행이 멈춘 상태입니다.
  • 완료: 최종 응답 렌더링까지 끝난 상태입니다.
