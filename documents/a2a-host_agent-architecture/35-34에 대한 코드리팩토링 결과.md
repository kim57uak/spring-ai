#### 2. **Progress 진행률 세분화 부족 (Section 4.F)** ⚠️

**현황:**
- `SupervisorAgentOrchestrator.java`:
  - composing 단계만 80% 표시 (163번 라인)
  - handoff 단계 진행률 표시 없음

**개선 필요:**
```java
// LangGraphSupervisorStateGraphFactory.java:250-257
// 현재: 진행률 표시 없음
swarmCoordinator.recordNodeEvent(context.getTaskId(), context.getSessionId(), "HANDOFF_EVALUATE", "Handoff directives evaluated", Map.of(...));

// 권장: SupervisorProgressSupport 사용
emitProgress(progressSink, SupervisorProgressSupport.STAGE_HANDOFF, 60, "Handoff 지시를 검증합니다...", Map.of(
    "validationCount", validations.size(),
    "acceptedCount", acceptedCount
));
```


**문제점:**
- handoff 노드는 `swarmCoordinator.recordNodeEvent()`로만 기록
- UI trace에 진행률 표시가 누락될 수 있음
- 문서 4.F에서 요구한 "공통 포맷 사용" 원칙 미준수

**해결 방법:**
- `LangGraphSupervisorStateGraphFactory`가 `ProgressEmitter`를 의존성으로 받아야 함
- 또는 `SupervisorAgentOrchestrator`가 graph 실행 중 progress를 추적해야 함
